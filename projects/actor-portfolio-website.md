# Michael Udeoji — Actor Portfolio Website

**Category:** Creative web development · Digital portfolio · Casting presentation  
**Status:** Local HTML package and browser preview observed; public deployment not independently verified (13 November 2026).

## Purpose
Present an actor's professional biography, selected film/TV credits, photographs, and casting contact in a shareable, mobile-friendly web portfolio.

## Documented components
- HTML entry point (`index.html`) with `images/`, `posters/`, and `videos/` directories.
- Four selected photographs: brown-suit portrait, blue-suit seated portrait, outdoor red-carpet photograph, and black-outfit festival photograph.
- Film and TV credit sections, actor biography, and Instagram contact **@michaeludeoji**.
- QR-code panel and a separate promotional QR poster intended to open the public portfolio.
- Netlify-oriented package including a `.netlify/` directory and deployment instructions.

## Quality-control and release checklist
1. Confirm the final public Netlify URL and that the site loads on desktop and mobile.
2. Change the website header to **UDEOJI MICHAEL** (rather than **MICHAEL IKENNA**) as requested.
3. Generate a QR code from the *verified public URL*; replace the QR on the promotional poster and test it using multiple phone cameras.
4. Confirm that each gallery image, video, navigation item and Instagram link works.
5. Keep original media rights and client permissions in mind before publicly uploading source images.

## Scope and evidence
This case study documents work discussed and browser screenshots of the portfolio, not a verified live production deployment. The QR in the original poster was reported not to resolve to the portfolio; no claim of a working replacement is made here. The public URL can be added after deployment and scanning are verified.

## Related skills
HTML website packaging, visual content curation, web portfolio presentation, QR-based sharing, release QA, and creative project coordination.
